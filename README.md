# RAG_DMS
The Pharma DMS RAG Assistant is a Retrieval-Augmented Generation (RAG) system designed to answer queries from a Pharma Document Management System.

# objective
To build a RAG-based assistant that:

Connects to a Pharma DMS database (documents + metadata)

Retrieves only approved and latest version documents

Provides citation-based answers

Logs user queries for governance tracking

Prevents unsafe SQL execution

# Backend
Flask
Python 3.10+

# Database
PostgreSQL
FAISS (vector indexing)

# AI / Embeddings
OLLAMA Embedding

# Other Tools
SQLAlchemy
GitHub 


# Model Architecture

User Query

Embedding Generation

Vector Search (pgvector / FAISS)

Governance Filter(Validation) (Approved + Latest Version)

Context Assembly

LLM Response Generation

Response + Citations


# Validation Layer
Only SELECT queries allowed
Does not Allow Unsafe commands like DROP,DELETE,ALTER

# Metrics

## Accuracy - Percentage of correct answers generated by the system.

## Retrieval Recall – Percentage of questions where the correct document was retrieved.

## Refusal Rate – Percentage of questions where the system returned "Insufficient evidence" due to lack of approved data.
